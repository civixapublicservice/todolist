# 📝 Todo Application

A modern and responsive Todo Application built using **React (Vite)**. The application allows users to manage daily tasks efficiently with authentication, CRUD operations, search functionality, dark mode, and local storage support.

---

## 🚀 Features

- 🔐 Dummy Login Authentication
- ➕ Add New Todo
- ✏️ Edit Existing Todo
- 🗑️ Delete Todo
- ✅ Mark Todo as Complete/Incomplete
- 🔍 Search Todos
- 🌙 Dark Mode / Light Mode
- 💾 Local Storage Persistence
- 📱 Responsive Design
- 🎨 Modern User Interface

---

## 🛠️ Technologies Used

- React
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3

## ⚙️ Installation

Clone the repository

```bash
git clone <repository-url>
```

Go to the project folder

```bash
cd vite-project
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
